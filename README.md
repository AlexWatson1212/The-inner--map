# The Inner Map

A production-ready first version of **The Inner Map**: a practical, non-diagnostic field guide for neurodivergent adults who want to understand their patterns, capacity and needs.

## Experience

- Recognisable Start Here doorways
- A private First Signal Map that runs entirely in the browser
- A 30-second low-capacity route
- Copy, plain-text download and print handover
- Evidence and ethical-boundary page with UK support routes
- Responsive, keyboard-accessible navigation and forms
- Reduced-motion support, metadata, sitemap, robots and 404

## Local development

```bash
npm run dev
```
